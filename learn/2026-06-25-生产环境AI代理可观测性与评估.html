SECTION 01 · A 层核心

Trace 与 Span：Agent 可观测性的骨架

Trace（用户查询："帮我订明天去上海的机票"）
 └─ Span：Controller Agent（路由/编排）
      └─ Span：意图识别 Agent
      └─ Span：航班搜索 Agent
           └─ Span：调用航班 API
           └─ Span：解析结果
      └─ Span：订票 Agent
           └─ Span：调用支付 API
      └─ Span：生成最终回复

关键点：
• Trace = 一个用户任务的完整生命周期
• Span = 任务中的单个步骤
• 结构 = 树形（Span 可嵌套子 Span）
• 多代理 = 树更深更宽，但一个任务仍是一个 Trace

无可观测性（黑盒）

只知道整体耗时 8 秒、成功/失败。无法定位哪一步慢、哪一步贵、哪一步错。

有可观测性（玻璃盒）

每一步的延迟、成本、输入输出透明可查。能精确到"是航班 API 超时"还是"LLM 生成太慢"。

SECTION 02 · A 层核心

在线评估 vs 离线评估：迭代闭环

离线评估 ──→ 部署 ──→ 在线监控 ──→ 收集新失败案例
    ↑                                        │
    └────── 添加到离线数据集 ←── 优化代理 ←──┘

离线评估                          在线评估
├─ 受控环境 + 已知答案测试集      ├─ 生产真实流量 + 实时监控
├─ 可嵌入 CI/CD 防止回归         ├─ 发现测试集无法预见的问题
├─ 可重复 + 明确准确性指标        ├─ 捕捉模型漂移 + 意外查询
└─ 确保上线前质量                 └─ 反映真实环境行为

核心结论

两者不是二选一，而是串联闭环。离线保证上线前质量，在线覆盖离线没考虑的边界情况，在线发现的新 case 回流到离线测试集，持续迭代。

SECTION 03 · A 层核心

成本管理三策略：缓存 → 路由 → 小模型

用户请求进来
  │
  ├── 缓存层先拦 ──→ 命中？直接返回（成本 ≈ 0）
  │                       适合：高频重复 + 答案稳定
  │                       不适合：个性化强 / 上下文相关
  │
  └── 未命中 → 路由模型判断复杂度
                 │
                 ├── 简单任务 → 小模型（SLM）
                 │              适合：意图分类 / 参数提取
                 │
                 └── 复杂推理 → 大模型（LLM）
                                适合：多步推理 / 创意生成

三策略串联逻辑

缓存是第一道防线（拦截最多请求）→ 路由是第二道（动态分发到合适模型）→ 小模型是整体架构决策（某类任务根本不需要大模型）。三者不是三选一，而是依次串联。

SECTION 04 · B 层理解

关键指标与埋点思路

六大监控指标

延迟 / 成本 / 请求错误率 / 用户反馈（显式+隐式）/ 准确性 / 自动评估指标（LLM 评分 / RAGAS）

OpenTelemetry 埋点

自动 Span（框架集成）+ 手动 Span（自定义业务数据如 user_id、session_id）。MAF 原生支持 OTel。

SECTION 05 · 学习复盘

薄弱点 & 亮点

可观测性价值只说了 debug

首答只提到"排查错误和优化"，遗漏了成本管理、安全合规审计、持续改进循环等价值维度。经补充后覆盖完整。

缓存适用边界判断不够精确

只说了"有固定答案"，更准确的判断标准是"高频重复 + 答案相对稳定"。个性化强/上下文相关的请求不适合缓存。

三策略初始认知为三选一

第一轮答 Q2 时把三策略当独立选项，经引导后理解为串联使用：缓存做围栏 → 路由做分发 → 小模型做兜底。

在线/离线闭环自主推出

不仅说出了"两者互补"，还自主推导出"在线发现的 case 回流到离线测试集"的迭代闭环机制——这正是材料的核心观点。

"缓存做围栏"表述精准

最终检索时用"缓存做围栏"一词概括了缓存作为第一道防线的角色，形象且到位。

多代理 × Trace 的跨章节联想

主动联想到"多代理系统中 Trace/Span 的层级会变深"，并尝试用"子 Trace"概念表达——方向对，说明跨章节连接能力在增强。
