SECTION 04 ─── 今日新发现红点 · 重重标记

"句尾糊弄动词" · 触发 5 次 · 最顽固红点

这是今天 D7 之前没注意到的新元层级红点。它和 5/13 的"爷爷化倾向"、 5/14 的"经验模糊随便说"是同一家族里的不同变种—— 你大脑的精度衰减不在概念层，在语言的尾段。

───────────────────────────────────────────────── 今日"句尾糊弄动词"完整触发记录 ───────────────────────────────────────────────── 题 3 第 1 轮 ：上下文【构建】 第 1 次 题 3 第 2 轮 ：context 上【优化】 第 2 次 题 3 第 3 轮 ：对 context 进行【处理】 第 3 次 → 命名 + 焊死 题 4 第 1 轮 ：在隔离上下文里【做处理】 第 4 次 → 红点立刻复发 题 5 第 2 问 ：进行任务的【处理】 第 5 次 ⚠️

家族总称： "句子末端的精度漏气"——前半段努力精确，后半段用"构建/优化/处理/管理"自动填空。 这不是知识漏洞，是作答习惯。

糊弄词 · 不能再用

构建 / 优化 / 处理 / 管理 / 进行

特征：动作类宽泛词，任何对 context 做事都能用这些词描述—— 所以它们没有指向、没有信息量。

具体动词 · 应替换

读取 / 清空 / 切换 / 回传 / 节约 / 隔离 / 派发

特征：能精准描述"信息从哪到哪"的动词。 下次作答前先想三秒钟句尾动词，再下笔。

SECTION 08 ─── 横向连接 · 跨章节复用

这一节和你以前学过的什么相关？

与 RAG 检索系统 —— 都在解决"context 太贵"

同一爷爷理念：context 是稀缺的资源，所以两者都只把精华放进 context。

儿子层差异： RAG 是"内部精华化"——脏活在 context 内部干，但只塞精华一小段； subagent 是"外部隔离化"——脏活在另一个 context 里干，主对话只接摘要。

→ D7 题 3 通过这一组对比焊死了"内部精华化 vs 外部隔离化"口诀。

与 AI 智能体三要素 —— Plan Mode 是规划/行动权限拆分的实例

在 AI 智能体三要素里，"规划"和"行动"是两个独立要素。 Plan Mode 用权限切换把这两个要素显式拆成两个阶段—— 只读权限阶段做规划，写权限阶段做行动。

Plan Mode 的工程价值（你 Q4 自悟的金句）： 把回退成本从【回退操作】降级为【回退计划】—— 在动手之前发现错误，比动手之后回退便宜得多。

→ 这是智能体设计原则在工具层的具体体现。下次自己设计 agent 时记得： 不是"一个 agent 干所有事"，是"规划阶段和行动阶段的权限要拆开"。

与 5/13 学习当天 —— 三个老坑 D7 全部复发或检测

坑 1（把"现象"当"机制"）： D7 触发——"Lost in the Middle"答成"注意力机制"。形式不同，本质相同。

坑 2（把 Plan Mode 当 subagent）： D7 没触发——但通过"subagent 启动新 agent 实例，Plan Mode 不启动新 agent，只切权限" 这一句反向焊死。

坑 3（用术语贴标签代替展开解释）： D7 触发——Q2 (b) 第 1 轮"开启 subAgents"一句话搪塞，被指出后展开三段式。

→ 5/13 的三个老坑，D7 触发 2/3——说明"踩过的坑还会再踩"，但能更快爬出来。这就是 D7 的真实状态。

与 5/14 D1 元学习觉醒 —— "蒙错比蒙对珍贵" 二次落地

5/14 D1 你给自己焊死的元学习信条是"蒙错比蒙对珍贵 · 边界感比知识量更重要"。 那次的具体场景是：老师给 (A)(B)(C) 三选时主动选 B = "我蒙的"。

D7 二次落地： 这次没有 (A)(B)(C) 选项，是你自己主动划出"我不知道"的边界—— "我这个真忘记了"。从被动选边界 → 主动划边界，是元意识更深一阶。

→ 这件事比答对一道题珍贵 100 倍。你的元学习信条已经从"知道"变成"用得上"。

与 5/11 分层钥匙 —— "上下兄弟问三句"再次救命

D7 题 1 (a) 把现象答成爷爷"注意力机制"——分层钥匙拎出"现象层 vs 爷爷层"边界，自我修正。
