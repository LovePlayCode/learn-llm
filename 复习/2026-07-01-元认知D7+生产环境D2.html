SECTION 01 · 元认知 D2 · 基础验证

改策略不只改答案 · 无状态三缺失 · 纠正型vs先发式

焊死

元认知 vs 纠错

普通纠错改答案（换酒店X→酒店Y），元认知改策略（"选最便宜" → "选最高评分"）。方向首答对，精度经磨锐通过。

秒出

LLM 无状态性

"无状态"关键词秒出。三缺失方向对：决策历史存储、评估机制、策略切换逻辑。措辞需更具体。

通过

纠正型 RAG vs 先发式加载

触发时机：任务中 vs 任务前。类比：考试时翻书 vs 考前放公式表。补充：触发条件还包含"信息质量不够"。

SECTION 02 · 元认知 D7 · 跨章节综合

战术vs战略 · 协调层元认知 · 动态觉察切短N

通过

酒店 Agent 元认知三步

执行（按策略输出）→ 反思 Reflection（审视策略本身）→ 策略切换。核心：中间多了审视策略这一步。

2/3首答对

Over-Reflection 三场景判断

A不反思(简单查询)✓、B反思(连续三轮不满意)✓、C需反思(新类型首次失败=策略质疑信号)——经引导修正。

通过

ReAct vs ReAct+Reflection

ReAct 思考是战术级（下一步做什么），加 Reflection 升级为战略级（我的做法本身对不对）。

引导后通过

元认知 × 多代理

放在协调层（Orchestrator）。审视的不是个体输出对错，而是任务分配、协作模式、Agent选择等策略级决策。首答混淆了"质检"和"策略审视"。

方向对

元认知 × 错误累积

元认知=动态觉察，在错误刚发生时阻断传播链。vs checkpoint=固定位置插暂停点。两者配合：checkpoint兜底，元认知主动刹车。

元认知切短 N 的机制对比：

┌────────────────────────────────────────────────┐
│  checkpoint（固定位置）                          │
│  Step1 → Step2 → [存档点] → Step3 → Step4      │
│  错误发生在 Step3 → 从存档点重试                 │
│  特点：预设位置，被动等待                         │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│  元认知（动态觉察）                              │
│  Step1 → Step2(策略错) → Reflection发现!         │
│                        → 立刻停下换策略重来       │
│  特点：主动觉察，早发现早止损                     │
└────────────────────────────────────────────────┘

配合使用：元认知是主动刹车，checkpoint是安全网兜底。
Over-Reflection 判断口诀

不该反思：简单任务 / 熟悉任务的常规小错

该反思：连续失败 / 新领域首次失败 / 用户反复不满意

核心判断：错的是"答案"还是"策略本身"？如果可能是策略有问题 → 反思。

SECTION 03 · 生产环境可观测性与评估 D2

Trace/Span 树形结构 · 评估闭环 · 成本三策略串联

修正后通过

Trace / Span 结构

Trace = 一个完整任务的生命周期。Span = 任务中单个步骤，可嵌套子 Span，整体是树形结构。首答误将 Span 限定为叶子节点，修正后通过。

精准

评估迭代闭环

离线测试 → 部署上线 → 在线收集真实 case → 回流离线测试集 → 优化 → 重复。一句话抓住核心循环。

完整

成本三策略串联

缓存做围栏（拦截高频重复）→ 路由做分发（判断复杂度）→ 小模型做兜底（简单任务不浪费大模型）。串联顺序和决策逻辑完整。
